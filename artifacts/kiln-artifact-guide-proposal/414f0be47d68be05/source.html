Kiln’s artifact guide and design system

Inter is the chosen font. Every new artifact must support light and dark themes, defaulting to the reader’s system setting.

This document records the accepted design and the evidence behind it. The full, maintained authoring guide lives in the repository and the MCP server.

Decisions 0 open, 4 settled

Use Inter

Settled

Inter is bundled locally through Fontsource. No Anthropic fonts, look-alike families or Google Fonts requests are required. Code and compact metadata use the system monospace stack.

Support both themes

Settled

Kiln owns the System, Light and Dark switch. System is the default. Explicit choices persist across pages and reloads.

Allow subject palettes

Settled

Kiln supplies the defaults. A subject-specific brand may override colors and typography, provided every color has a dark value and remains readable.

Deliver the guide through MCP

Settled

The server sends short instructions on connect and serves the complete guide at kiln://guide/authoring.

  2. The full guide resource, including token names, theme markup, authoring patterns and HTML starter code.

  4. A tool description that points back to the guide before code is submitted.

The light and dark contract

Every artifact supports both themes. Kiln sets data-theme="light" or data-theme="dark" on the root element, including inside HTML frames.

  • The shared switch lives outside artifact content. Do not draw another switch inside an artifact.
  • Use shared --kiln-* colors or Tailwind dark: classes.
  • Define any subject colors for both themes. Without a theme mark, standalone content follows the system preference.
  • SVG labels, diagrams, charts and status pills must remain readable in both themes.
  • Exercise the real controls in both themes before reporting success.

What they share

  1. Color tokens at the top. Background, surface, line, text, muted, an accent with a soft wash, and status colors that each have a matching wash. Every token has a light and a dark value.
  2. One theme convention. The system setting decides by default, and a data-theme mark on the page overrides it. Neither artifact draws its own switch.
  3. One column, most useful content first. The tracker even states its layout plan in a comment at the top of its styles.
  4. One sans family plus mono. Mono carries metadata: links, dates, counts, IDs and status pills.
  5. Status as small pills. Colored text with a dot, on a matching wash.
  6. Counts next to section titles, such as "0 open, 8 settled" or "6 of 8 phases on staging".
  7. Data apart from layout. Content sits in one list, and a script draws it. The script uses plain text, never raw HTML, and only allows https links.
  8. Loading, empty and failed states with a sentence explaining what will appear.
  9. Accessibility basics. Labelled sections, pressed states on filter buttons, labelled progress bars, visible focus, and motion only when the reader allows it.
  10. The reader's language. The report is written in Indonesian and says so in its lang attribute.

Neither artifact uses Claude's fonts or the cream and clay palette. Claude's artifact look is a structure and a token discipline, not a fixed palette. So Kiln should fix the structure and the theme convention, and supply a default palette and fonts that an artifact may replace.

Parts worth reusing

Now panel

Three columns: working on, next, waiting on you. The waiting column turns red when something needs the reader.

Decision card

Question, context, options, a recommended answer on a tinted box, then "Decided: …" with a date. Open ones first.

Phase timeline

A rail of short phase codes joined by a line. Each phase has a title, a status pill, a summary, links and its dependencies.

Step checklist

A progress bar, then collapsible steps. Done steps are struck through. Active phases open by default.

Log

Newest first. A date column in mono, then the phase code and one line of what happened.

Summary and stat cards

Key and value pairs for each option, then small cards for the winners, with a label, a value and a note.

Results table

Scrolls sideways on phones, with sticky headers, tier badges, score colors, aligned numbers and filter buttons.

Callout and sources

A tinted note with an accent edge for caveats. A numbered source list and a dated footer at the end.

Limits and non-goals

  • Kiln has no managed database or private backend. Trackers store their data in the source and receive updates through new revisions.
  • Older source revisions can still have fixed colors. The theme switch does not rewrite their content.
  • Markdown, SVG and Mermaid as dedicated artifact formats are not part of this change.
  • Artifact pages and source code are public. The supplied private reference files are not published.
