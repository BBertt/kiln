Espay first card payment: UAT building blocks (#631)

This page lists the four endpoints of the first card payment. It shows the endpoint that each row of the Espay UAT script tests.

Scope

1 card payment

The scope is the first card payment only. The customer pays once with a card on an Espay page. Arcane sends the request, then it confirms the result with a status lookup. Card data stays on the Espay page and does not reach Arcane.

Endpoints

4 endpoints, 2 in each direction

Arcane calls E1 and E2 on the Espay host. Espay calls E3 and E4 on the Arcane host. The URLs of E3 and E4 are registered in the Espay merchant portal.

# Direction Method and path Purpose Success code

A success code is the response code of the SNAP reply. When a call to Arcane fails, the Espay portal shows [0031] Rejected, Error komunikasi dengan mitra.

UAT rows and the endpoint that each row tests

Row What the test does Endpoint Applicability

Applies means that the row is in scope for the SNAP Host to Host setup. To confirm with Espay means that the sample marks the row for an embed kit or non SNAP merchant. Pending implementation means that Arcane and Espay have not agreed the reply for that row.
