What changed, and what the browser proved

Verification of Kiln’s Inter font, theme switch and guide delivery. These are observed results from the original nine artifact migrations.

Summary

Font delivery

The browser resolves the body to Inter Variable. Font files come from the installed Fontsource package.

Theme behavior

System is the default

A manual Light or Dark choice persists. Switching back to System clears the stored override.

Guide delivery

Fresh client verified

The server returns instructions, a Markdown guide resource and two prompts, each containing the guide.

Transitions exercised

  • System mode followed an emulated change from light to dark.
  • A Light override stayed light after a reload while the system was dark.
  • Arrow-key navigation moved the selection to Dark.
  • Gallery preview pages received the new theme and hid their embedded toolbars.
  • HTML frames resolved to rgb(250, 249, 245) in light and rgb(25, 25, 25) in dark.

Limits

Historical revisions retain their source colors. Shared dependencies and the rendering shell still apply to them.

This report records behavior, not a complete accessibility certification. It does not claim that every possible chart or user-supplied color passes contrast checks.

Recommendation

Author new artifacts with the shared tokens. Do not add a second theme switch inside an artifact. Check both themes and the artifact’s actual controls before reporting success.

Method and sources

  1. Managed Chromium loaded each local artifact page. The shared switch changed themes while computed body styles were observed inside HTML frames.
  2. A fresh MCP client listed resources and prompts, read the guide, and requested the tracker prompt.
  3. astro check, npm run build and the existing two-test suite passed.
  4. The authoring guide defines the expected behavior.
